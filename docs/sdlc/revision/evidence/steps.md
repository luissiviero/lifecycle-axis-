# Operational step inventory — lifecycle-axis- AI-native SDLC kit

Scope: every action the kit prescribes, ordered as the lifecycle runs. Lens A = the life of one work
item. Lens B = adopting the kit into another repository. Maintain-loop steps follow.

Abbreviations in "Enforcement": **advisory** = prose/skill only; **deterministic** = a hook, a script,
a CI job or a check that mechanically refuses; **human gate** = a person must act.
"State": *implemented* = code exists and runs; *declared-not-built* = written down, no code path;
*inert* = code exists but cannot fire in this repo today; *superseded* = replaced by a later item.

Note on citations: the approval script is `scripts/approve.py`; the signing script is
`scripts/sign.py`. `approve.py` line numbers are from the file itself.
