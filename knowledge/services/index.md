# Services

Empty for now — this kit ships as a single-service starter. Add a file here the first time a second service,
external dependency, or shared table needs a description that more than one work item will reference.

**File naming.** `knowledge/services/<service-name>.md`, one service (or one table, prefixed `table-<name>.md`) per
file. `title` is the service's name; `description` is one sentence on what it does and who owns it; link to its
runbooks, its metrics, and the decisions that shaped it.
