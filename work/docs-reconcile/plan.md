## Risks
- Risk: a timestamp rewrite lands in the same PR as a text edit and the two disagree → mitigation: step 7 runs after
  every edit and skips edited files, which carry the edit instant; the oracle tolerates 24 h.
- Risk: a lesson pointer line pushes `CLAUDE.md` past 120 → mitigation: one clause per line; measured in step 5.
- Risk: `yaml.safe_load` rejects a value the kit's parser accepted beyond the five (e.g. a bare `@handle`) → mitigation:
  step 1 runs the checker over every tracked `.md` before any edit; anything extra is quoted and listed under Deviations.
- Risk: the adopter's seeded `## Lessons learned` heading collides with the fragment heading → mitigation: the fragment
  heading is `## Lessons (one file each in knowledge/lessons/)` (spec C2).
- What this could break: `verify.sh` gains a check that can fail on a new document; nothing else is executable.
- Options considered and not taken: a CI timestamp check (OKF frozen, consensus item 10); grouping the lessons (intent
  Q2); editing `.sdlc/approvers.yaml` or `sdlc-gate.yml` (rule 3; proposals in the PR body).
