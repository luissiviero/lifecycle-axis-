name and its consequence for the merge, so the spec says, under C1, that the code lands by the owner's click
and the item parks with `parked: ready PR #<n>; click needed (scripts/check_artifact_chain.py)` from a
ledger-only pull request (`.claude/skills/sdlc-run/SKILL.md`, "The detour rule", step 5; the decision record

acceptance test is withdrawn. The trigger is committed in this record's front matter and quoted in the spec's C1.

defect. There is no low-only subset of the fix to carve out (the intent's Q3 answer and the owner's revision of
it on 2026-09-18 both say so), so the only alternatives are a park with a supervised remainder that would be
the whole item again, or this route, which loses nothing and frees the pointer.

## Reviewer: security-reviewer (claude-opus-5)
Trigger reproduced independently: `python3 scripts/check_detour.py --slug chain-check-without-gh --paths
scripts/check_artifact_chain.py scripts/test_chain_no_gh.py` prints `scripts/check_artifact_chain.py: locked

The `None` path buys an agent nothing. On `check_artifact_chain.py:928` an `ok is None` result with an
agent-identity author is a `FAIL`, and `:940` gives an agent-authored commit with **no** trailer the
identical `FAIL`: on the skipped path the trailer is inert, so the pull-request-51 finding (mirrored in

unset the token at `check_artifact_chain.py:232` and reach the same tuple -- the delta available to an
attacker is zero, and the defect only converts a silent skip into an unreadable one.

`.github/workflows/sdlc-gate.yml` supplies `GH_TOKEN` with `actions: read` on `ubuntu-latest`, and that
workflow is under `PROTECTED_PATHS` (`.sdlc/config.env:9`) with `scripts/check_control_plane.sh:55,128`

`REFUSED` for any file under a locked prefix and `.sdlc/delegation.yaml:64` lists

`python3 scripts/check_artifact_chain.py` from the pull request's own head checkout and
`check_control_plane.sh` guards only `PROTECTED_PATHS`, which excludes this file -- CI on that pull request

## Closing note

`verdict: revise` and there are at least as many sections as the policy's `min-reviewers`. A `keep`
verdict, on any reviewer, or too few sections, means the agent does not re-sign: it stops here and
